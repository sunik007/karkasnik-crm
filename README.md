# Каркасник CRM

Мобильная CRM для управления клиентами и заказами в бизнесе по строительству каркасных домов.

## Первая версия

- карточки клиентов;
- телефон, WhatsApp / Telegram;
- город и адрес строительства;
- источник клиента, комментарий и дата обращения;
- заказы, привязанные к клиентам;
- размер дома, площадь, комплектация, стоимость, предоплата, сроки и статус;
- поиск клиентов и заказов;
- мобильный интерфейс;
- локальное сохранение данных в браузере через `localStorage`.

## Запуск

Откройте `index.html` в браузере. Для постоянного адреса можно опубликовать проект через GitHub Pages.
